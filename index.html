CPU და GPU

CPU და ვიდეო ბარათიკომპიუტერის ორი უმნიშვნელოვანესი კომპონენტი — დანიშნულება, მუშაობის პრინციპი და ტექნიკური მახასიათებლები

ამ გაკვეთილზე განვიხილავთ CPU-ს (Central Processing Unit) და GPU-ს (Graphics Processing Unit), მათ ნაწილებს და ერთმანეთისგან განსხვავებას.

ყველა ილუსტრაცია ინტერაქტიულია: მიიტანეთ მაუსი ნებისმიერ ნაწილზე (ტელეფონზე — შეეხეთ) და ქვემოთ გამოჩნდება მისი სახელი და განმარტება.
მიიტანეთ მაუსი ნაწილზეაქ გამოჩნდება განმარტება.
მიზნები

რა არის CPU?

CPU (Central Processing Unit) — კომპიუტერის ცენტრალური დამამუშავებელი მოწყობილობა. ქართულად — პროცესორი. ასრულებს პროგრამების მიერ მოთხოვნილ გამოთვლით და ლოგიკურ ოპერაციებს.

  • პროგრამების გაშვება
  • ოპერაციული სისტემის მუშაობა
  • ფაილების დამუშავება და გამოთვლები
  • ინსტრუქციების შესრულება
  • სხვა მოწყობილობების მუშაობის მართვა
CPU შეგვიძლია წარმოვიდგინოთ როგორც კომპიუტერის ერთ-ერთი მთავარი „ტვინი“.

ბირთვები (Core) და ნაკადები (Thread)

Core — ბირთვი: პროცესორის დამოუკიდებელი დამამუშავებელი ერთეული. რაც მეტი ბირთვია, მით მეტი ამოცანა მუშავდება პარალელურად.

Thread — ნაკადი: სამუშაოს დამუშავების ლოგიკური ერთეული. ზოგ პროცესორს ერთ ბირთვზე ორი ნაკადის დამუშავება შეუძლია.

2 Core — ორბირთვიანი4 Core6 Core8 Core
ანალოგია: ბირთვი — მზარეული, ნაკადი — მისი ორი ხელი. 6 მზარეული 12 ხელით ერთდროულად უფრო მეტ კერძს ამზადებს. მნიშვნელოვანია არა მხოლოდ რაოდენობა, არამედ არქიტექტურაც.

CPU

სიხშირე: Base Clock და Boost Clock

Clock Speed გამოხატავს, რა სიჩქარით მუშაობს პროცესორის საათის ციკლი. იზომება MHz და GHz-ში. 3.5 GHz = 3.5 მილიარდი ციკლი წამში.

Base Clock — საბაზისო სიხშირე (მაგ. 3.2 GHz).
Boost Clock — უფრო მაღალი სიხშირე (მაგ. 4.6 GHz), რომელზეც პროცესორი გადადის მაღალი დატვირთვისას, თუ ტემპერატურა და ენერგია იძლევა საშუალებას.

CPU-ის წარმადობა მხოლოდ GHz-ით არ განისაზღვრება — მნიშვნელოვანია არქიტექტურა, ბირთვები და Cache.

Cache: L1, L2 და L3

Cache — ძალიან სწრაფი მეხსიერება პროცესორის შიგნით. მისი მიზანია ხშირად საჭირო მონაცემებისა და ინსტრუქციების სწრაფად მიწოდება.

  • L1 — ყველაზე სწრაფი და მცირე, უშუალოდ ბირთვთან.
  • L2 — უფრო დიდი, ოდნავ ნელი.
  • L3 — კიდევ უფრო დიდი, საერთოა ყველა ბირთვისთვის, ამცირებს RAM-ზე მიმართვებს.
ანალოგია: L1 — ხელში გიჭირავთ, L2 — მაგიდაზე დევს, L3 — ოთახის თაროზე, RAM — სხვა ოთახში, SSD — ბიბლიოთეკაში.
მიიტანეთ მაუსი დონეზემოცულობა და დაყოვნება (სავარაუდო მნიშვნელობები).

არქიტექტურა და წარმოების ტექნოლოგია (nm)

CPU Architecture აღწერს, როგორ არის პროცესორი ორგანიზებული და როგორ ასრულებს ინსტრუქციებს. ის მოქმედებს წარმადობაზე, ენერგოეფექტურობაზე, ბირთვების მუშაობაზე და ტექნოლოგიების მხარდაჭერაზე.

ორი პროცესორი შეიძლება ერთნაირი სიხშირით მუშაობდეს, მაგრამ განსხვავებული არქიტექტურის გამო განსხვავებული წარმადობა ჰქონდეს.

TDP და პროცესორის გაგრილება

TDP — Thermal Design Power დაკავშირებულია პროცესორის თერმულ/ენერგეტიკულ დიზაინთან და გაგრილების მოთხოვნებთან. იზომება ვატებში (W), მაგ. TDP: 65W.

TDP არ არის ზუსტი მუდმივი ენერგომოხმარება. რეალური მოხმარება დატვირთვის, მოდელისა და რეჟიმის მიხედვით იცვლება.

CPU მუშაობისას სითბოს გამოყოფს, ამიტომ საჭიროა გაგრილება. მთავარი მიზანი — ტემპერატურის კონტროლი.

  • Air Cooling — heatsink, fan, thermal paste
  • Liquid Cooling — სითხე, ტუმბო, რადიატორი, ვენტილატორები
მიიტანეთ მაუსი გამაგრილებლის ნაწილზეჰაერის და სითხის სისტემები.

ჩაშენებული გრაფიკა — iGPU

ზოგ CPU-ს აქვს ჩაშენებული გრაფიკული პროცესორი — Integrated GPU (iGPU). ამ შემთხვევაში ცალკე ვიდეო ბარათი ყოველთვის აუცილებელი არ არის.

iGPU საკმარისია:

  • ოფისისთვის და ინტერნეტისთვის
  • ვიდეოების საყურებლად
  • მსუბუქი გრაფიკული სამუშაოებისთვის
  • მარტივი თამაშებისთვის
მოთხოვნად 3D თამაშებსა და პროფესიონალურ გრაფიკაში ხშირად საჭიროა ცალკე, ძლიერი GPU.
მიიტანეთ მაუსი სქემის ნაწილზეროგორ მუშაობს ჩაშენებული გრაფიკა.
GPU

რა არის GPU?

GPU — Graphics Processing Unit, ქართულად — გრაფიკული დამუშავების პროცესორი. სპეციალიზებულია დიდი რაოდენობის გრაფიკული და პარალელური ოპერაციების დამუშავებაში.

  • თამაშები და 3D გრაფიკა
  • ვიდეომონტაჟი
  • ვიზუალიზაცია და 3D მოდელირება
  • AI გამოთვლები
  • გრაფიკული პროგრამები
ანალოგია: CPU — რამდენიმე პროფესორი, რომლებიც რთულ ამოცანებს სწრაფად ხსნიან. GPU — ათასობით მოსწავლე, თითოეული მარტივ მაგალითს ხსნის, მაგრამ ყველა ერთდროულად.
მიიტანეთ მაუსი CPU-ზე ან GPU-ზებირთვების რაოდენობა და ტიპი.

GPU და ვიდეო ბარათი ერთი და იგივე არ არის. GPU — გრაფიკული პროცესორია (ჩიპი). ვიდეო ბარათი — უფრო დიდი მოწყობილობა, რომელიც მოიცავს GPU-ს და სხვა კომპონენტებს.

  • GPU — მთავარი გრაფიკული პროცესორი
  • VRAM — ვიდეომეხსიერება
  • გაგრილება: ვენტილატორები, რადიატორი, სითბური მილები
  • კვების ელექტრონული ნაწილი (VRM)
  • ვიდეო გამოსასვლელები
  • PCB — ბეჭდური დაფა

Bottleneck — წარმადობის შემზღუდავი

Bottleneck („ბოთლის ყელი“) — კომპონენტი, რომელიც მთელი სისტემის წარმადობას ზღუდავს.
